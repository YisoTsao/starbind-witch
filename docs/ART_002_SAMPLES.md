# ART-002｜林緣與戰鬥區引擎樣本

2026-11-24，G1 選定 A 林緣＋B 戰鬥區。以下是一組供 G2 審閱的 Unity 樣本，可用同一個森林場景檢查角色、環境、法術和 HUD 的相對比例。

| 類別 | 本次樣本規格 | 審閱重點 |
|---|---|---|
| 森林 | 三種既有樹形沿用透明輪廓、樹幹與碰撞，冠內加入由左上受光的葉簇。四種 32×32 草地變體使用兩個相近綠色，邊緣同色。既有道路、水岸與地標沿用。 | 林緣是否有探索層次？中央前搖範圍能否一眼辨認？ |
| 角色 | 依現有魔女 36 格、每格 64×56 的原圖做內緣描線與 alpha 清理；腳底錨點 (32,4)、既有切片及動作時序沿用。怪物採現有菇王作為辨識對照。 | 帽尖與鞋底在綠地和橘紅預警內是否清楚？ |
| 火彈 | 8 格、每格 48×36。深紅外形、橘色火身、淺黃熱核；尾焰擺動，亮部留在行進方向。命中與消散沿用既有特效事件。 | 移動方向能否從火身形狀辨認？命中時是否仍看得到角色？ |
| HUD | 同一火形簡化為 32×32 技能圖示，接入現有 Q 槽；沿用紫金九宮格、Fusion Pixel 繁中字型、魔典翻頁與輸入。 | 技能欄圖示能否和場中火彈對應？選單字形以實機顯示為準。 |

## 重現

樣本 PNG 位於 `art-source/art-002/overlay/Assets/_Game/Art/`，由同目錄上層的 `build_samples.py` 生成（Python、Pillow）。從乾淨的 98d8e1f 專案副本開啟預覽：先將 overlay/ 下的 Assets/ 合併至**副本**，讓 Unity 沿用原有 .meta 切片與 GUID，再進入 Forest 的 Play Mode。正常施放火彈，前往菇王區觀察預警，開啟魔典檢查介面。自動取證使用現有 GameEvidenceCapture；本次副本用 Unity 6000.6.10f1，專案指定版本為 6000.6.8f1。

樣本角色沿用既有參考角色圖，其來源權利仍待確認。畫面可用於本次內部審閱。不同裝置的縮放、低階機效能與真人操作感仍待驗收。

## 實際畫面與觀察

- [全森林](evidence/art-002/F00_forest_overview_native_2048.png)及[入口](evidence/art-002/F01_forest_entrance_hud.png)可比較林帶與可走動區。綠樹已有葉簇層次，部分沿用的藍樹仍是大色塊，林緣密度低於 A 概念圖。
- [菇王預警](evidence/art-002/F07_boss_phase1_telegraph.png)中，兩側橘紅邊線在安靜草地上連續可見；區名浮字仍與菇王上身重疊。
- [施放](evidence/art-002/S01_fire_bolt_cast_trail.png)與[命中](evidence/art-002/S02_fire_bolt_blast.png)來自原火彈操作流程。[魔典](evidence/art-002/U02_grimoire_page1.png)由 Play Mode 開啟，截圖使用既有雙相機取證，細小中文字沿用原工具的顯示限制。
- 七個覆蓋檔與原始匯入尺寸一致。36 格魔女、8 格火彈逐格非空且 alpha 僅 0/255，四種草地變體的邊界皆同色。測試報告見同目錄 XML。

後續 QA 已調整遊戲的通知位置。菇王預警區的最新畫面見 [修正後的實際截圖](evidence/world-graybox/boss-notice.png)。樣本送審的歷史截圖保留供比較。
