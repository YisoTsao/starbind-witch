# 美術製作入口

現有七張樣本的作者檔保存在 art-source/art-002/，引擎截圖與每類限制見 [四樣本報告](ART_002_SAMPLES.md)。後續替換時使用原 GUID、切片與腳底錨點；逐批保存同鏡頭對照，檢查尺寸、透明邊、材質取樣與角色走過遮擋物的結果。每筆原作與授權證明須可追溯至資產清單。
