## 狀態定義

| 狀態 | 定義 |

| **Reference Only** | 只能看，不能裁切使用。造型、構圖或色彩參考 |
| **Extractable** | 物件輪廓獨立、沒有壓到文字或其他物件，可裁成單張 RGBA 作為**重繪底稿** |
| **Needs Cleanup** | 已裁出，需降採樣到原生密度、調色盤索引、去光暈、修輪廓、重新打光 |

## 2. 圖 A：紫幻森林巫女村落.png（目標場景）

狀態：**Reference Only**，不切割、不當背景。

### 2.1 量測

- 美術像素 ≈ 3.15 螢幕 px → 原生 ≈ **530×299**，接近 480×270 參考解析度。
- 畫面約 16.6 × 9.3 tiles（以 32 px tile 計）。
- 魔女約 33 美術 px 高；門約 32 px 高；主路約 2 tiles 寬；左上花樹約 115 px 寬；小屋可見部分約 160 px 寬。
- 平均亮度 0.57、飽和 0.50：明亮白天。

### 2.2 場景構成（由北到南）

| 區域 | 內容 | 對應 Tilemap / 物件層 |
|---|---|---|
| 北中 | 魔女小屋：紫瓦弧形屋頂、圓窗、紫藤花瀑、煙囪、拱門、石階、燈籠、月亮旗、窗邊藥水架、木桶、木箱、花盆 | 牆＝World（Y 排序），屋頂＝Foreground，石階＝Path |
| 北側橫線 | 木柵欄（小屋兩側往東西延伸） | World + Collider |
| 西北 | 大粉花樹、綠樹 | 樹幹 World、樹冠 Foreground |
| 西 | 高台上的池塘→瀑布→下層水池（含荷葉）、土色懸崖立面 | Water、Cliff、GroundDetails（荷葉） |
| 中央 | Y 字型土路：小屋門口→中央→南方出口、東向支路 | Path（需 Rule Tile 草/土邊緣） |
| 中西 | 柵欄段、雙向路牌、紫色旗幟 | World + 互動 F（路牌） |
| 東北 | 紫色帳篷攤位（藥水、書）、花樹 | World |
| 東 | 石板路片段、紫水晶噴泉（可作「傳送星盤」） | Path 裝飾、World + 互動 |
| 南 | 樹樁、發光藍紫蘑菇、岩石、灌木樹、南側懸崖 | GroundDetails / World / Cliff |

### 2.3 可行走區域判斷

- 可走：草地、土路、石板路、石階。
- 不可走：水面、懸崖立面、樹幹、建築牆、柵欄、攤位、噴泉外圈、岩石、樹樁。
- 不擋人：小花、草叢、荷葉（在水上，本來就不可走）、旗幟上半部。
- 有高低差：西側高台與南側懸崖。Phase 0 處理方式：高台上下皆在同一物理層，懸崖立面放碰撞，階梯處留缺口（見 `TECH_ARCHITECTURE.md` §6）。

### 2.4 遮擋需求（Y 排序）

- 玩家走到小屋屋簷、樹冠、帳篷頂**後方**時應被遮住；走到前方時在上層。
- 解法：牆/樹幹/攤位用腳底 Pivot＋自訂軸 Y 排序；屋頂與樹冠放 Foreground，玩家位於其下時淡出至約 40% 透明。
