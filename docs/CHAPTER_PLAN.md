# 全章節藍圖與製作依賴

故事、任務 ID、解鎖與 Boss 延用 [既有世界與任務](STORY_WORLD_QUESTS.md)。星露村作共同安全據點。下表的第二章至終章為可逆 L0/L1 提案。灰盒中事件與遭遇以錨點表示。第一章既有實作的範圍以 GAME_DESIGN_V3 為準。

| 章 | 路線與玩家動詞 | 選走的理由、Boss 與後續依賴 | 時間與實作狀態 |
|---|---|---|---|
| 月影森林 | 村莊備戰，過蘑菇林道，啟動祭壇，修橋或燒藤，迎戰菇王 | 東支線取書頁；勝後回村研究。與礦坑銜接為草案 | 正式 Demo 目標一局 10–12 分鐘；可玩草稿＋獨立 L1 路線模型 |
| 星核礦坑 | 礦口至爆破點、晶礦大廳、斷橋、核心礦室 | 救礦工的死巷；電晶體與礦車是主要機關，晶核魔像與地下水脈銜接湖區 | 僅 L1；遊時待機關實裝後測 |
| 星輝湖 | 營地分東西浮島，再會合於水晶遺跡 | 湖岸殘頁支線；導電架橋及會模仿構築的湖影，通往浮島航線 | 僅 L1；遊時待測 |
| 失落觀星台 | 山腳雪道交錯上行，調整折射鏡，到廣場與塔頂 | 搜索舊觀測紀錄；守護者的光束與月蝕道路承接終章 | 僅 L1；遊時待測 |
| 黑月城塞 | 城門、三塔、中央大廳，環路可返回 | 探索古塔側室；三學派試煉與扭曲魔典為草案，結局待決 | 僅 L1；遊時待測 |

第一章正式製作須先確認四類樣本、參考角色來源權利、範圍及回歸結果。首章地下城在技能的通用範例出現，現行 GDD 的既定 Demo 以菇王棲地作高潮；增建獨立地下城須先定範圍。後續章節須 G4 後逐章決定是否投入任務、戰鬥與美術製作。
