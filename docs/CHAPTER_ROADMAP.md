# 章節製作路線

五章配置、試走順序與地區特色見 [章節藍圖](CHAPTER_PLAN.md)。目前可驗收五章的入口、主線、支線與跨章返回。正式內容產能依以下順序投入。

1. 星露村／月影森林完成樣本驗收，針對角色、任務指引、素材權利及 10–12 分鐘首玩節奏關閉缺口，送 G4。
2. 確認後續章節提案後，以星核礦坑先走完礦工救援、爆破開路、晶礦遭遇與結算的 L2 切片，通過後才做 L3 正式素材。
3. 湖區驗證兩條浮島路線與導電機關；觀星台驗證折射與返程；城塞驗證三塔條件與結局。各章分別測重進、防止重複給獎與實際完成時間。

跨章引用由 ZONE_MANIFEST.csv 與 ChapterRouteTests 維護。各關卡決策見 [製作清單](PRODUCTION_BACKLOG.md)。
