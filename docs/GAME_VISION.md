# 星痕魔女｜玩家體驗

從星露村的小屋出發，魔女可以練習法杖與蓄力魔彈，在工坊決定法術配置，再走進森林。沿途的敵群、可燃藤蔓、祭壇與升級選擇，讓同一段路因構築而有不同走法。擊敗菇王後將殘頁與材料帶回工坊，改變下一局的起手能力。

第一次五分鐘的驗收重點是認得角色、理解移動與施法、找到訓練場和森林入口。一局的既定目標為 10–12 分鐘；半小時內可觀察玩家是否願意用另一套主動／自動組合重進森林。三小時以上的成長節奏與後續章節留待實際內容測試。現有 GDD 定義單人 2D 俯視 RPG，首個交付切片為村莊、小屋與月影森林。美術採 A 林緣＋B 戰鬥區，先維持地形、角色、火彈與危險預警之間的辨識層次。

平台驗證以目前可建置的 macOS Player 與後續 Windows 目標分開記錄。低階機、真人反覆遊玩、商用素材與 Windows 實機結果仍待補。設計界線與操作細節依 [產品 GDD](GAME_DESIGN_V3.md)，實作進度依 [狀態表](PROJECT_STATE.md)。
