# 像素基準

一個地磚 32×32、32 PPU，攝影機參考尺寸 480×270。Point 取樣、關閉 mipmap 與壓縮，由 PixelArtImportRules 套用。以 480×270 原生與整數放大檢查帽尖、鞋底與預警邊；檢查透明邊時並排使用深色森林與淺色村路。

G1 的 A 林緣以左上光、分群葉簇與冷暗部表現樹冠。B 戰鬥區降低地面亮點密度，保留連續安全動線。畫面優先讀出敵方攻擊範圍，其次看主角、敵人與法術，最後才是地貌紋理。具體色票與主次參考見 [ART_DIRECTION](ART_DIRECTION.md)，實際樣本與瑕疵見 [ART_002_SAMPLES](ART_002_SAMPLES.md)。
