# 任務事件與存檔契約

現有結構由 ObjectiveTracker 推導目標；長期進度寫入 ProfileData.completedQuests。首次配置與勝利後研究共用既有清單，不增加存檔版本。既有舊檔沒有新旗標時，可於下一次符合條件的操作取得。

| 任務 | 觸發與持久化 | 驗收 |
|---|---|---|
| M-04 初次書頁 | 在工坊魔典台選擇合法 Q、E 或自動法術後，隨配置一起保存 configure_first_spell。 | 只開介面時尚無旗標；按法術按鈕後重讀得到旗標。重選不重複累加。 |
| M-08／09 勝利返回 | 菇王被擊敗後使用光門，結算並回村。 | 從村莊進森林，驗三階段、結果頁、回村出生點及磁碟中的勝利數／碎片。 |
| M-10 新的書頁 | 至少勝利一次，且成功支付一次研究時保存 research_after_victory。 | 材料不足、已滿級或首勝前研究都不能新設旗標。 |

後章事件採 [現有任務清單](STORY_WORLD_QUESTS.md) 的 M2 至 M5 ID。灰盒以地標的穩定 ID 掛接任務或遭遇位置，正式獎勵、NPC 對話與解鎖條件待後章定案。設計獨立 QuestLog 時須先驗證舊旗標遷移與重複發獎。
