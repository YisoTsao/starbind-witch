# Starbind Witch 法術特效美術規格

以深色森林和明亮村莊為基準。主體輪廓應在遊戲原生像素尺度上一眼可辨，亮度集中在撞擊點、冰晶稜面或雷弧主幹。先看得出攻擊的方向和範圍，再看見煙、粉塵與符文。

## PixelFX 研究

- PixelFX 以低解析度像素圖層畫輪廓，另外用加色光層畫能量，並依前後層和角色合成。Starbind 採同樣的分工，用點採樣翻頁精靈畫材質，疊局部加色光與有上限的場景燈光。[README](https://github.com/patch-gg/pixelfx#how-it-works) · [Authoring](https://github.com/patch-gg/pixelfx/blob/main/docs/AUTHORING.md)
- 冰霜新星用近大遠小的晶簇描述爆發，落地後才化成冰塵。火龍捲以收窄基部、前後不同亮度的螺旋和上升餘燼塑造旋轉體積。雷弧的最亮區沿著共用的鋸齒路徑聚在落點，分枝更細、消散更早。[Frost Nova](https://github.com/patch-gg/pixelfx/blob/main/src/fx/ice/frost-nova.js) · [Fire Tornado](https://github.com/patch-gg/pixelfx/blob/main/src/fx/fire/fire-tornado.js) · [Chain Lightning](https://github.com/patch-gg/pixelfx/blob/main/src/fx/lightning/chain-lightning.js)
- 攻擊依事件分成起手、飛行或駐留、命中、餘韻。PixelFX 支援以來源點輸出透明序列，Starbind 以現有施法、命中和反應事件同步美術，使用為本專案繪製的圖形與動畫。[Acting](https://github.com/patch-gg/pixelfx#acting) · [Sprite sheets](https://github.com/patch-gg/pixelfx#use-one)

## 共用規則

| 元素 | 深色與中間色 | 亮面 | 輪廓與動勢 |
| --- | --- | --- | --- |
| 火 | 酒紅、朱紅、橙 | 金黃、暖白 | 鬃焰沿速度反向伸展，爆開後成為冷卻火星與上飄灰煙 |
| 冰 | 靛青、鈷藍、湖藍 | 淺青、冷白 | 長矛和多面晶簇，硬稜線在最亮幀閃現，碎片呈菱角 |
| 雷 | 葡萄紫、靛紫 | 淡紫、金白 | 主幹分段折線，細分岔根植於主幹，擊地後向外爬行 |
| 風 | 深青、低飽和藍綠 | 薄荷、霜白 | 負空間、斷裂長曲線和向內旋入的粒子，薄亮邊短暫閃現 |
| 奧術 | 深紫、玫紫 | 丁香、珍珠白 | 星形、菱形和軌道，讓追蹤魔彈與蓄力彈各有輪廓 |

- 32 PPU、Point、無 mipmap 與壓縮。硬像素提供主體，半透明留給煙、軌道殘影與加色光。亮核心用短段和小面積，局部光暈在主體外緣迅速衰退。
- 投射物畫向右並隨飛行方向轉向。預告與符文貼地，垂直部件以落點為 pivot。圓形面積提示以判定半徑縮放，煙、碎片與餘燼可短暫越出邊界。
- 起手與命中使用 16–30 fps 的局部動畫。高亮偏向前幾幀，餘韻有方向性。循環特效使用首尾連續的相位，消失時保留淡出的餘韻。
- 常見自動攻擊保持小面積。反應和超載可使用較強的局部光，保留全螢幕閃光設定與同時播放上限。高密度戰鬥優先保留施放點、命中點和敵方預警。

## 資產維護與驗收

執行 `python3 tools/art/spell_vfx.py` 產生圖片與切片 manifest，再使用 Unity 的 **Starbind → Import Spell VFX** 更新 GameDatabase。方向性投射物用中心 pivot，垂直特效以接地點為 pivot。檢查單發施法、持續區域、元素反應和多敵人疊加時的遊戲畫面，以及關閉螢幕閃光時的局部提示。

[森林場景的 Unity 實機擷取](evidence/spell-vfx/forest-spells.png)涵蓋火焰、冰晶、雷擊、風渦、火龍捲與超載。
