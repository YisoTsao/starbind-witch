# 主要介面與返回路徑

| 情境 | 操作與可見回饋 | 驗收 |
|---|---|---|
| 移動探索 | WASD 移動，F 對最近互動物執行操作；小地圖與世界圖讀既有場景目標。 | 村莊 NPC 對話、屋門往返、橋頭碰撞與出口。 |
| 森林戰鬥 | Q/E 主動、R 超載，技能槽顯示配置與冷卻。頂部 Boss 血條、地面預警、左側暫時通知各自有顯示位置。 | 同屏 Boss 與通知時，魔女前方仍可看見完整預警邊線。 |
| 工坊 | F 開啟魔典台或研究桌；首次配置顯示放入槽位的提示。成功配置及研究持久化。 | 重開介面與磁碟重讀一致；失敗支付不改旗標。 |
| 局內暫停 | 魔典可檢視三頁，升級時選卡再回戰鬥；設定調整閃光與音量。 | 關閉介面後恢復輸入與時間，檢查繁中字型與焦點。 |
| 結算 | 勝利返回村莊，失敗回工坊；下一次開檔可取用帶回的材料。 | 結果頁只結算一次，載入落在正確 SpawnPoint。 |

UI 圖像與尺寸見 [UI 美術規範](UI_ART_DIRECTION.md)。手把、超寬螢幕及正式上市可讀性待目標裝置驗收。
