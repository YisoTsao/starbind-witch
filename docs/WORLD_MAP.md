# 世界路線與返回規則

正式 Demo 由星露村通往小屋與月影森林；小屋門與森林回程點沿用既有 SpawnPoint。森林 Boss 勝利後經光門結算回村，失敗回小屋。保存位置、獎勵與研究沿用原本 ProfileData。星盤地區選擇與劇情鎖仍為 STORY_WORLD_QUESTS §3.2、§5 的候選方案。

章節審圖器依序連接「森林模型 ↔ 星核礦坑 ↔ 星輝湖 ↔ 失落觀星台 ↔ 黑月城塞」。白點自入口出發，方向鍵每次走一格，在紅色 Boss 錨點按 F 前往下一章，在下一章綠色入口按 F 返回原章 Boss 錨點。章節下拉選單方便審圖，重新選章由入口起步。這條連線不寫入玩家存檔。

各章設計與玩法狀態見 [章節表](CHAPTER_PLAN.md)，每個地標及出口見 [區域清單](ZONE_MANIFEST.csv)。
